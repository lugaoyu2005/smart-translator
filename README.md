# Smart Translator · 智能翻译

一款 Windows 桌面翻译工具。**划一下、框一下，译文就盖在原文上**——不用切窗口、不用复制粘贴。

不联网也能用：自带离线翻译模型和本地 OCR，断网、无 API 密钥时照样能翻。

---

## 下载安装

到 [Releases](https://github.com/lugaoyu2005/smart-translator/releases) 页面下载，三种形式选一个：

| 下载哪个 | 适合谁 | 说明 |
|---|---|---|
| **`Smart-Translator_0.4.20_x64-setup.exe`** | 大多数人 | 安装包，自动装好依赖、创建开始菜单和桌面快捷方式 |
| `Smart-Translator_0.4.20_x64_en-US.msi` | 需要 MSI 部署 | 同上，企业分发常用格式 |
| `Smart-Translator_0.4.20_x64_green.zip` | 不想安装 | 解压即用，配置和模型都放在同一个文件夹里，删文件夹=彻底卸载 |

**绿色版注意**：解压后 **`onnxruntime.dll` 必须和 `smart-translator.exe` 待在同一个目录**，删掉它程序无法启动（离线翻译和本地 OCR 依赖这个推理库）。

**运行环境**：Windows 10 / 11 64 位，需要系统有 WebView2 运行时（Win11 和较新的 Win10 自带）。

## 能做什么

### 📸 截图翻译 —— 主力功能

按 **`Alt+E`**（可改）→ 屏幕冻结成一张图 → 拖框选中要翻的文字 → **译文直接盖在原文上**。

- **冻结画面**：触发瞬间把屏幕定格，视频、动画、游戏里的文字也能准确框选（可在设置里切成实时画面）
- **覆盖样式**：黑底白字 / 白底黑字 / 无背景（只留文字加重影）
- **严格对齐模式**：框多大字就多大，紧贴原文排版；默认是弹性模式，不强求贴合
- **覆盖层显示**：可设默认显示「原文 / 译文 / 上次」
- **框选操作**：拖选多块、双击选整段、Ctrl 加选、左键单击隐藏或显示、右键退出
- 菜单里的按钮（引擎、语言、原/译、关闭、设置）可以**增删和拖动排序**

### 🔤 划词翻译

选中任意程序的文字，按划词快捷键，译文浮在旁边。默认未设置，需要自己去设置页指定一个组合键。

### 🌐 在线翻译 · 7 家可选

百度翻译、有道智云、小牛翻译、DeepL、腾讯云翻译、阿里云翻译、**自定义 AI（OpenAI 兼容）**。

自定义 AI 这一项可以接 DeepSeek、Kimi、通义千问、智谱 GLM，甚至本地跑的 Ollama——只要是 OpenAI 兼容接口就行，支持加多个供应商。**名称怎么填就怎么显示**（填 `deepseek` 就显示 `deepseek`），所以名称不能重复。

> 用哪家都得自己填 API 密钥，软件不附带任何密钥。腾讯云、阿里云、DeepL 有免费额度，长期用建议优先考虑。

### 💻 离线翻译 —— 不联网也能翻

两条路线：

- **OPUS-MT**（默认）：轻量，按语言对下载 30–80MB。中↔英有专用模型直达；日/韩/俄/法/德/西/葡经英语中转
- **NLLB-200**：单个模型覆盖 200 种语言，任意语言对直达，质量更好，但要下约 850MB，短句约 1–2 秒，长句更慢

**完全离线运行**，不产生任何网络请求。第一次用某个语言对会自动下载模型，之后就一直存在本地。

在「设置 → 翻译引擎 → 当前翻译源」里选「离线翻译（本地模型）」即可强制走离线，不选的话它会在联网引擎都失败时自动兜底。

### 🔍 OCR 引擎（截图时识别文字用）

| 引擎 | 特点 |
|---|---|
| **Windows 内置 OCR**（默认） | 本地、免费、系统自带，零下载 |
| **RapidOCR 本地** | 本地、免费、离线，识别率更好，首次下载约 15MB 模型 |
| **有道 OCR** | 云端，按量计费 |

### 📚 术语库

自己维护的词汇对照表，翻译时优先套用。支持 CSV / TSV / TXT / JSON 导入，内置一份 45 条的符号纠错包。可以建多套方案随时切换。

### 🕘 翻译历史

自动记录每次翻译，最多保留 500 条（新的在前），支持搜索、复制、删除。

### ⚙️ 系统集成

系统托盘、开机自启动、单实例（重复启动会唤出已有窗口而不是开第二个）。

## 上手三步

1. **装好打开**。默认启动后藏在托盘里，点托盘图标就能唤出（想让它启动就显示，去设置里改）。
2. **填密钥**。设置 → 翻译引擎，勾上你要用的引擎，填 API 密钥，再选一个「当前翻译源」。
3. **开始用**。按 `Alt+E` 截图翻译，或者设置一个划词快捷键。什么都不填也行——直接用离线翻译和本地 OCR。

### 快捷键

| 功能 | 出厂默认 | 说明 |
|---|---|---|
| 截图翻译 | **未设置** | 建议设一个，如 `LAlt+Q` |
| 划词翻译 | 未设置 | 不设置就不注册全局热键 |
| 唤出主窗口 | 未设置 | 同上 |
| 反转原文/译文 | 未设置 | 截图窗口内可用 |

- 修饰键**区分左右**：`LCtrl` `RCtrl` `LAlt` `RAlt` `LShift` `RShift` `LWin` `RWin`，想只让左边的键触发就写 `LAlt` 而不是 `Alt`
- 组合键必须含修饰键，不支持单个按键
- `Del` 或 `×` 清除，`ESC` 退出截图翻译

## 数据存在哪

绿色版和安装版的配置都在程序目录下，**纯文本、随时可备份、删掉即恢复默认**：

| 文件 | 内容 |
|---|---|
| `settings.json` | 所有设置和 **API 密钥**（⚠️ 别分享给别人） |
| `terms.json` | 术语库和符号包 |
| `history.json` | 翻译历史 |
| `models\` | OCR 和离线翻译模型（删了会重新下载） |

**卸载干净**：安装版卸载后直接删掉程序目录；绿色版删文件夹即可，不留注册表垃圾。

## 常见问题

**启动后找不到窗口？**
默认隐藏到托盘了。点托盘图标，或按「唤出主窗口」快捷键。也可以去设置里改成启动就显示。

**截图快捷键按了没反应？**
多半是撞车了——被系统或其他软件占用。去设置页看冲突提示，换一个组合键。另外，如果**当前窗口是以管理员身份运行的**（比如某些安装程序），普通权限的全局快捷键可能收不到按键，这时把本软件也以管理员身份启动即可。

**离线翻译第一次特别慢？**
第一次要下载并加载模型（NLLB-200 约 850MB），之后会缓存，就快了。

**RapidOCR 第一次用要等？**
首次会自动下载约 15MB 模型，之后完全离线。

**删模型提示被占用？**
请走设置页的删除按钮，程序会先释放模型再删文件。

**设置搞乱了想恢复默认？**
删掉 `settings.json` 重启即可。

**会不会偷偷上传我的内容？**
不会。用在线引擎时，文字发给**你自己配置的那家服务商**（百度、DeepL 等），密钥也是你自己的；用离线翻译和本地 OCR 时全程不出本机。软件本身没有遥测、没有后台上报。
