# 窗口行为守则（截图翻译窗口）

> 来源：BUG报告-截图翻译窗口风暴.md（2026-09-09 焦点闪烁事故）的复盘固化。
> 涉及窗口生命周期的任何改动，**必须**先读本文，交付前必须跑
> `scripts/window-focus-check.ps1`（见文末）。

## 铁律（任何改动不得违反）

1. **截图窗口禁止参与焦点竞争**
   - 扩展样式必须包含 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`
     （main.rs setup 处设置，永久保留）
   - 后果警示：缺 NOACTIVATE 时，窗口任何 show/点击都会抢系统前台——
     引发全系统焦点闪烁（窗口阴影/任务栏/输入法指示器乱跳）
   - 代价须知：NOACTIVATE 窗口内 WebView2 收不到键盘（keydown 失效），
     因此退出依赖「后端 ESC 监视线程 + 前端 poll_esc 轮询」双保险，不得移除

2. **全屏窗口的显隐 = 整个桌面重绘**
   - 截图窗口（全屏）在可见屏幕上 show/hide 会让文件管理器/桌面闪烁
   - 预热必须在**屏幕外**进行：preheat_screenshot 先 set_position(-32000,-32000)
     再 show，600ms 后 hide 并恢复原位
   - 前端首帧渲染完成后通过 `invoke("preheat_screenshot")` 触发（有去重）

3. **触发/退出链路的焦点语义**
   - 触发：trigger_screenshot = hide → 取消穿透 → show → SetForegroundWindow
     （前置 ALT 击键 hack 绕过前台锁定）→ spawn_esc_watcher → emit 事件
   - 退出：exit-screenshot 事件 / poll_esc 轮询 / 右键 / 复制完成 →
     前端 exit() = 复位状态 + 恢复穿透 + win.hide()

## 交付前必跑：系统级行为检查

```powershell
powershell -File scripts/window-focus-check.ps1   # 需应用正在运行
```

检查内容（45 秒采样 + 触发链路）：
- 截图窗口待命态全程不可见（桌面零重绘）
- 前台被应用占据次数 = 0（待命态）
- 触发后窗口显示且前台到手；ESC 后窗口隐藏且前台释放
- 重复触发无窗口风暴（无高频显隐）

任何一项不符合 = 引入了焦点/显隐回归，禁止交付。
