# 撤销描边样式，Ctrl 多选反馈统一用原生选区高亮

## 问题
上一轮给"已选块"加的蓝色描边（`.block.picked`）就是之前被否掉的"选框"样式，需撤销。

## 修复方案
1. **删除 `.block.picked` 描边样式 + className 判断**——块外观恢复纯净，不再有任何框类标记
2. **Ctrl+双击反馈改为原生选区本身**：不再清除选区，而是和普通双击一样 `selectNodeContents` 让整段保持原生实心蓝选中态（片段累积逻辑不变，同块再次 Ctrl+双击=取消）
3. **Ctrl+拖选**：上一轮已改为松手后选区保留可见，维持不变
4. 视觉规则从此统一：**所有选中态（拖选/双击/Ctrl+双击）都是同一种原生贴字高亮**，无任何框/描边/徽标

## 收尾
- `npm run build` 验证（纯前端改动，无需 cargo）
- git 提交
